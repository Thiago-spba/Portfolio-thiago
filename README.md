## Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/Thiago-spba/Portfolio-thiago.git

# Instale as dependências
cd Portfolio-thiago
npm install

# Rode em desenvolvimento
npm run dev

# Build para produção
npm run build
```
